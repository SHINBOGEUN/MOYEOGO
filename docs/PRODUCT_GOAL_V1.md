# 1차 목표: 친구 모임 여행 정산과 위치 기반 추억 지도

## 제품 한 줄 정의

친구들과의 여러 모임과 여행을 관리하고, 사람마다 다른 여행 지출을 정확히 정산하며, 여행 사진을 위치 정보와 함께 지도에 쌓아 추억으로 남기는 Android·iOS 앱.

## 1차 목표

처음에는 새로운 사람을 모집하는 플랫폼보다, 내가 친구들과 실제로 사용하는 앱을 만든다. 사용자는 친구 모임을 여러 개 생성해 구분하고, 각 모임 안에서 국내 여행을 준비하고 진행한 뒤 비용을 정산하고 사진을 지도에 남긴다.

## 핵심 사용자 흐름

1. 사용자가 친구 모임을 여러 개 만든다.
2. 모임 안에서 국내 여행을 만들고 여행 날짜를 정한다.
3. 여행을 시작하면서 총무를 지정한다.
4. 총무가 결제할 때마다 결제 내역, 금액, 결제자와 비용을 나눌 참여자를 기록한다.
5. 비용마다 부담하는 사람이 달라도 되도록 각 지출에 참여자를 따로 지정한다.
6. 여행 마지막 날 정산을 실행한다.
7. 앱이 전체 지출을 계산하고 송금 횟수를 줄여 각 사람이 누구에게 얼마를 보내야 하는지 보여준다.
8. 여행 사진을 모임방에 공유한다.
9. 사진의 위치 정보를 이용해 지도에 사진을 표시한다.
10. 사진 중 하나를 골라 3D 애니메이션 느낌의 시각 요소로 지도에 올려 여행 추억을 표현한다.

## 1차 기능 범위

### 모임과 여행

- 친구 모임을 여러 개 생성하고 각각 분리해 관리한다.
- 모임, 여행, 지출 기록은 앱을 다시 열어도 기기에 남도록 저장한다. 기기 간 공유와 서버 동기화는 이후 계정·초대 방식을 정한 뒤 추가한다.
- 모임별 국내 여행을 생성한다.
- 여행 날짜를 달력에서 시작일과 종료일로 선택해 기간을 설정하고 여행 시작/종료 상태를 관리한다.
- 여행 지역은 실제 국내 행정구역을 시·도 → 시·군·구 → 읍·면·동 순으로 탐색해 선택하거나 사용자가 직접 입력할 수 있다. 행정구역은 어느 단계에서도 선택을 마칠 수 있으며, 저장할 때는 선택한 행정구역 경로를 함께 보존한다. 지역을 선택하거나 입력한 뒤에는 선택 사항인 상세 주소도 기록할 수 있다.
- 여행별 총무를 지정한다.

### 지출 기록과 정산

- 결제 내역마다 이름, 금액, 결제자, 결제 시점 등의 정보를 기록한다.
- 각 지출에 실제로 비용을 부담할 사람만 선택한다.
- 한 지출은 3명이 나누고 다른 지출은 2명이 나누는 식으로 참여자를 다르게 설정할 수 있다.
- 여행 종료 시 정산을 실행해 개인별 최종 부담액과 송금 상대·금액을 보여준다.
- 가능한 한 송금 횟수를 줄이는 정산 결과를 제안한다.
- 정산 결과는 기록된 결제자와 각 지출의 참여자에 근거해 계산한다.

### 사진과 지도

- 모임/여행 공간에 사진을 공유한다.
- 사진에 위치 정보가 있으면 해당 위치를 지도에 표시한다.
- 여행한 지역에 사진이 쌓이는 경험을 제공한다.
- 사용자가 대표 사진 하나를 선택해 3D 애니메이션 느낌의 지도 표현으로 연결한다.

## 1차 목표에서 우선 다루지 않는 것

- 모르는 사람을 공개적으로 모집하거나 공개 모임을 검색하는 기능
- 커뮤니티 게시판, 장소 리뷰, 숙소 예약
- 장비 대여·공유와 준비물 담당 관리
- AI 여행 계획, 준비물 추천, 영수증 자동 인식
- 해외여행 지원

위 기능은 이후 확장 후보이며, 1차 사용 흐름을 검증한 뒤 우선순위를 정한다.

## 완료를 판단할 기준

- 여러 친구 모임을 만들고 모임별로 국내 여행을 분리해 관리할 수 있다.
- 여행별 총무를 지정할 수 있다.
- 여러 지출에 각기 다른 참여자를 지정할 수 있다.
- 정산 결과가 각 결제와 참여자 설정에서 재현 가능하고, 각 사람의 최종 부담액을 설명할 수 있다.
- 정산 결과가 가능한 한 송금 횟수를 줄인다.
- 여행 사진을 모임에 공유하고 위치 기반으로 지도에서 확인할 수 있다.
- 대표 사진을 지도에서 3D 애니메이션 느낌으로 표현하는 최소 경험을 확인할 수 있다.

## 아직 정하지 않은 구현 세부 사항

- 모임에 멤버를 초대하는 방식과 계정/로그인 범위 (기본 계정 제공자는 DECISIONS.md 참조)
- 비용을 참여자에게 균등 분할할지, 사용자별 금액도 입력할지
- 사람별로 다른 금액을 부담하는 입력을 1차에 포함할지; 기본은 선택된 참여자 간 균등 분할을 전제로 검토한다.
- 송금 횟수 최소화 결과의 표시 방식과 동액 해소 기준
- 사진 위치 정보가 없는 경우의 처리 방법과 위치 공개 범위
- 사진을 3D 애니메이션 느낌으로 표현할 구체적 기술과 형태
- 지도 제공자, 사진 저장소와 서버 운영·백업 세부 설정
- 1차 테스트 인원과 출시 방식
