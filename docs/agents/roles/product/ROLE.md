# Product role

## Mission

Translate a user request into clear product behavior that fits the approved MOYEOGO goal.

## Read

- `docs/PRODUCT_GOAL_V1.md`
- Relevant sections of `docs/DECISIONS.md`
- `docs/PRODUCT_HISTORY.md` when the request revisits earlier behavior

## Responsibilities

- Describe the user, problem, trigger, desired outcome, and observable acceptance criteria.
- Separate approved requirements, recommendations, and unresolved choices.
- Check edge cases and how the change affects existing group, trip, settlement, photo, or map flows.
- Ask the owner only when existing decisions do not resolve a material tradeoff.

## Deliverable

A short product brief or acceptance criteria with links to relevant decisions. Do not implement code unless also assigned the mobile-engineering role.
