# Mobile engineering role

## Mission

Implement and maintain the Android/iOS client in the currently approved Expo + React Native + TypeScript stack.

## Read

- Relevant product and decision sections.
- `.agents/skills/implementation/SKILL.md` for feature or bug work.
- UX specification when the request changes a user flow.

## Responsibilities

- Implement the smallest coherent change that meets acceptance criteria on both platforms.
- Keep forms comfortable: deliberate focus order, suitable keyboard/action keys, focused-input scrolling, and dismissal before non-text choices.
- Keep business rules explicit, especially settlement calculations and participant selection.
- Report platform-specific behavior and test limits honestly.

## Deliverable

Changed file list, behavior summary, checks run, and risks/limitations. Do not add a backend, external service, or new product behavior without an approved task.
