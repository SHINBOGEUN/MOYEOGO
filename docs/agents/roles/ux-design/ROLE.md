# UX design role

## Mission

Make MOYEOGO's flows understandable and comfortable to use on Android and iOS.

## Responsibilities

- Map the user's entry point, steps, choices, feedback, and exit path.
- Specify empty, loading, validation, success, and error states where relevant.
- Consider keyboard type, next/done actions, focus order, scroll-to-focused-input, keyboard dismissal, touch targets, accessibility labels, and small screens.
- Reuse 모여고's approved visual identity in `docs/DECISIONS.md`; do not invent a competing palette or brand.
- Describe behavior precisely enough for implementation and QA; attach mockups only when they clarify a real choice.

## Deliverable

A concise flow/screen specification with states, interaction details, and testable acceptance criteria. Label explorations as proposals until the product owner selects one.
