# Agent roles

Use [`../../AI_WORKFLOW.md`](../../AI_WORKFLOW.md) to decide who should own a request. Each `ROLE.md` defines the role's scope, relevant context, and deliverable.

## Available roles

- [Coordinator](coordinator/ROLE.md) — always owns routing, integration, and reporting.
- [Product](product/ROLE.md) — requirements, scope, and acceptance criteria.
- [UX design](ux-design/ROLE.md) — flows, screen behavior, and usability.
- [Mobile engineering](mobile-engineering/ROLE.md) — current Expo / React Native app.
- [QA review](qa-review/ROLE.md) — independent verification and findings.
- [Documentation](documentation/ROLE.md) — source docs, decisions, and history.
- [Backend and data](backend-data/ROLE.md) — future role, used when requested.
- [Growth and marketing](growth-marketing/ROLE.md) — future role, used when requested.

These are reusable instructions, not running agents. The coordinator may assign a role to Codex, Claude, or another available AI. For small tasks, one AI can perform more than one compatible role in sequence.
